# Data

`APPL.xlsx` is the original workbook supplied for ECMT 674 Homework 4.

The assignment states that the `Daily` sheet contains:
- Open
- High
- Low
- Close

for Apple stock from January 2, 2015 through April 7, 2025.

The retained R analysis uses the `Close` column to construct daily log returns in basis points.
