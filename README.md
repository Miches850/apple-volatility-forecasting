# Reference Materials

The original ECMT 674 Homework 4 assignment and submitted homework files are retained privately outside this public repository.

The assignment required:
- return construction;
- `ndiffs()` stationarity/differencing assessment;
- ARIMA mean modeling;
- squared-residual ARCH diagnostics;
- four-lag squared-residual regression;
- ARCH and GARCH SIC comparison;
- 26 one-step-ahead volatility forecasts.

The repository documentation summarizes only the project requirements needed to explain the analysis.
